# SimpleCamera 2

## בנייה דרך GitHub (בלי Android Studio)
1. צור repository חדש ב-GitHub והעלה את כל תוכן התיקייה (כולל `.github`).
2. לשונית **Actions** ← Build APK (רץ אוטומטית ב-push, או Run workflow).
3. בסיום: בתחתית דף הריצה תחת **Artifacts** הורד `SimpleCamera-debug-apk` (בתוכו `app-debug.apk`).
   להתקנה צריך לאפשר "התקנה ממקורות לא ידועים".

## מצבים
רגיל, וידאו, מקצועי (EV/ISO/תריס), סריקת QR.

## תיקון איכות (ללא AI)
הגדרות ← "תיקון איכות" ← הפעל. אחרי כל תמונה נשמר עותק `_ENH` לצד המקור
(איזון רמות, הבהרת תמונות כהות וחידוד).

## הערה
האייקונים והלוגו נלקחו מאפליקציית המצלמה המקורית, לשימוש אישי.

## שינויים בגרסה 2.2
- שם חבילה (applicationId): `com.mediatek.camera`, עם רכיב `CameraLauncher` כמו במצלמה המקורית של המכשיר
- צילום מיידי: התמונה נשמרת ברקע ואפשר להמשיך לצלם; הצילומים בתור.
- פלאש מסך בסלפי מסונכרן: נשאר דלוק עד שהצילום באמת בוצע.
- הגדרות: גודל תמונה "מסך מלא" (ברירת מחדל) + איכות צילום (מקסימלית/גבוהה/בינונית/נמוכה).
- מקצועי: לחיצה נוספת על "מקצועי" מסתירה את הגדרות הצילום.
- זום: מציג את הגודל (למשל 2.3x) לשנייה.
- כפתורי עוצמת קול (ומקש מצלמה) מצלמים; בווידאו מתחילים/עוצרים הקלטה.
- התאמה לאפליקציית מערכת: תיקיית `system/` (Android.bp + הרשאות מראש), פתיחה ממסך נעול.
